# Java Data Structures and Algorithms

A Java practice repository for learning programming fundamentals and implementing common data-structure and algorithm problems.

## Topics currently represented

| Area | Examples |
|---|---|
| Basics | Number operations, reversing values, interfaces and introductory exercises |
| Arrays | Maximum element, reversing an array, pairs, stock-price practice and maximum subarray / Kadane's algorithm |
| Sorting and searching | Binary search |
| Chapter exercises | Practice organized into chapter folders |
| Control flow | Switch-case examples |

## Run an example

Install a JDK and verify that the Java compiler is available:

```bash
java -version
javac -version
```

Compile and run an individual source file from the repository root. For example:

```bash
javac Array/ArrayMax.java
java -cp Array ArrayMax
```

The class name and command may vary by source file. Check the class declaration and package statement before compiling.

## Suggested contribution format

For each new problem, include:
- A descriptive class and file name
- A short problem statement
- Example input and output
- Time and space complexity
- Edge cases where relevant

## Purpose

This repository is a learning notebook. Implementations may evolve as concepts are revisited and improved.
